# Play Some Cards

A small board game hub to play with friends in the browser. Create a room, share the 4-letter
code or link, play.

```
npm install
npm run dev        # open http://localhost:5033
```

- Web: React + Vite (`apps/web`)
- Server: NestJS + Socket.IO (`apps/server`)
- Game rules shared by both: `packages/shared`

Adding a game: `docs/adding-a-game.md`. Deploying: `docs/deploy.md`.
Working with AI agents: `AGENTS.md`.
