# Bộ âm thanh nghe thử Cờ tỷ phú

Mở `index.html` bằng trình duyệt để nghe từng tiếng hoặc cả bộ. Các file WAV là mono 16 bit, 44.100 Hz. Bảy hiệu ứng được tổng hợp bằng `../make_audio_preview.py`; tiếng nhận tiền, mua đất và vào tù dùng file Pixabay bạn cung cấp. Nhạc thắng lấy từ `games/tien-len/assets/tien-len-standings.mp3`. Chạy lại cần Python và ffmpeg.
